# Heart Protocol ❤ - Web & Mobile Edition

Phiên bản Web tương thích 100% trên điện thoại (iOS / Android) và máy tính, chuyển hóa trọn vẹn từ ứng dụng C# WPF `HeartProtocol`.

---

## 🌟 Tính năng nổi bật trên điện thoại
- **Giao diện Cyber-Romantic**: Tông màu đen huyền bí `#080A0F`, xanh mint neon terminal `#7CFFB2`, và đỏ hồng neon `#FF3158`.
- **Canvas Tim Bay & Nhịp Tim Sống Động**: Hiệu ứng tim đập 2 nhịp tự nhiên (`heartbeat`), mưa tim bay lơ lửng, nổ tung 75 trái tim khi chọn Đồng ý.
- **Máy đánh chữ Typewriter mượt mà**: Tự động cuộn theo dòng chữ trên điện thoại.
- **Hệ thống âm thanh tiếng nổ 💥 ĐÙNG! 💥**: Tự động mở khóa âm thanh trên trình duyệt di động (Safari iOS & Chrome Android) ngay khi nhấn Xác nhận.
- **Trọn vẹn 8 phân cảnh**:
  1. Xác minh danh tính: `Tuyết Mai`, `Mai`, `Bình`, `Yên Bình`
  2. Khởi tạo chương trình (Boot terminal)
  3. Quét hệ thống & Báo cáo bộ nhớ
  4. Trái tim bí mật đập rộn ràng
  5. Giải mã 3 mảnh ký ức (First, Second, Last)
  6. Phân tích danh tính & ASCII progress bar
  7. Lời tỏ tình chính thức kèm tiếng nổ và nút lựa chọn
  8. Hộp thư ghi chú chân thành của người viết

## 🚀 Hướng dẫn Deploy lên GitHub Pages (để mở bằng điện thoại)

### Bước 1: Khởi tạo Git & Commit
Mở Terminal tại thư mục này và chạy:
```powershell
git init
git branch -M main
git add .
git commit -m "Khoi tao Heart Protocol Web Edition cho dien thoai"
```

### Bước 2: Tạo Repository trên GitHub
1. Truy cập [https://github.com/new](https://github.com/new).
2. Đặt tên repository: `heart-protocol` (hoặc tên tùy thích).
3. Chọn chế độ **Public**.
4. Nhấn **Create repository**.

### Bước 3: Đẩy mã nguồn lên GitHub
Thay `<tai-khoan-github>` bằng username GitHub của bạn:
```powershell
git remote add origin https://github.com/<tai-khoan-github>/heart-protocol.git
git push -u origin main
```

### Bước 4: Bật GitHub Pages (Để lấy link gửi qua điện thoại)
1. Trong repository trên GitHub, chọn tab **Settings** (ở thanh menu trên cùng).
2. Ở cột bên trái, chọn mục **Pages**.
3. Tại phần **Build and deployment** -> **Branch**:
   - Chọn nhánh `main`.
   - Chọn thư mục `/(root)`.
   - Nhấn **Save**.
4. Chờ khoảng 1 - 2 phút, GitHub sẽ hiển thị đường link trang web của bạn:
   👉 `https://<tai-khoan-github>.github.io/heart-protocol/`

Bạn có thể sao chép đường link này và gửi qua Zalo / Messenger / iMessage để mở trực tiếp trên điện thoại!
